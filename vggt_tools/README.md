# VGGT experiment tools

This directory contains project-specific orchestration scripts and notebooks that
were previously stored as untracked files inside a checkout of
[facebookresearch/vggt](https://github.com/facebookresearch/vggt).

Install or clone VGGT separately. The scripts currently expect that checkout at
`/home/viplab/liukejia/project/vggt` and experiment data under
`/data/muufl_grid_50m_pipeline`. Update the constants at the top of each script
when using another environment.

Input images, generated NumPy arrays, GLB files, and other VGGT outputs are not
versioned in this repository.
